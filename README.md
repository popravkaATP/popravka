# Поправка — баллистический калькулятор

## 📲 Установить

| Телефон | Ссылка | Как установить |
|---|---|---|
| **Android** | [**Скачать popravka.apk**](https://github.com/popravkaATP/popravka/releases/download/latest/popravka.apk) | Открыть скачанный файл → «Установить» (или «Обновить») |
| **iPhone** | [**popravkaatp.github.io/popravka**](https://popravkaatp.github.io/popravka/) | Открыть в Safari → «Поделиться» → «На экран „Домой“» |

По ссылкам всегда открывается самая свежая версия.

---

Одно приложение в двух видах:

- **APK для Android** — настоящее приложение, ставится на телефон с Android 7 и новее.
- **Сайт-приложение (PWA) для iPhone и любых телефонов** — открывается в браузере и «устанавливается» на главный экран.

Оба варианта работают **без интернета**. Собирает их бесплатно GitHub, ставить Android Studio не нужно.

## Как получить приложение (один раз, около 20 минут)

### 1. Заведите аккаунт на GitHub
Зарегистрируйтесь на https://github.com, это бесплатно.

### 2. Создайте репозиторий
1. Нажмите **«+» → New repository**.
2. Имя: `popravka`.
3. Выберите **Public**: для бесплатного размещения сайта репозиторий должен быть публичным.
4. Нажмите **Create repository**.

### 3. Загрузите файлы проекта

**Способ А — через GitHub Desktop (рекомендуется, без ограничений):**
1. Установите программу https://desktop.github.com и войдите в свой аккаунт.
2. **File → Clone repository** → выберите `popravka` → **Clone**.
3. Скопируйте **всё содержимое** распакованной папки `popravka` (вместе со скрытой папкой `.github`) в папку, которую создала программа.
4. В GitHub Desktop внизу слева напишите `Первая версия` → **Commit to main** → **Push origin**.

**Способ Б — через сайт.** Сайт принимает до 100 файлов за раз, поэтому загружайте в два приёма:
1. **Add file → Upload files**. Перетащите всё, **кроме** папки `android`. Нажмите **Commit changes**.
2. Ещё раз **Add file → Upload files** и перетащите папку `android`. Нажмите **Commit changes**.

> Папка `.github` должна попасть в репозиторий: в ней хранятся инструкции для автосборки. На Mac скрытые папки показываются сочетанием Cmd + Shift + точка.

### 4. Включите сайт
В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

### 5. Подождите сборку (5–10 минут)
Откройте вкладку **Actions**. Там должны появиться две задачи: «Сборка APK» и «Публикация сайта». Когда обе станут зелёными, всё готово.

Если «Публикация сайта» успела упасть до шага 4, откройте её и нажмите **Re-run all jobs**.

### 6. Установите приложение

**Android:**
1. На телефоне откройте ваш репозиторий → справа **Releases → «Поправка — последняя версия»** → скачайте `popravka.apk`.
2. Откройте скачанный файл. Телефон попросит разрешить установку из этого источника: разрешите.
3. Если Google Play Защита скажет, что приложение ей незнакомо, нажмите «Всё равно установить». Так происходит со всеми приложениями не из магазина.

Файл `popravka.apk` можно пересылать друзьям в мессенджере.

**iPhone (и любой телефон):**
1. Откройте в **Safari** адрес `https://ВАШ_ЛОГИН.github.io/popravka/`.
2. Нажмите **«Поделиться» → «На экран „Домой“»**.
3. Откройте приложение с иконки **один раз при интернете**. После этого оно работает и без сети.

На Android этот адрес тоже работает: Chrome предложит «Установить приложение».

## Обновления

Измените что-нибудь в проекте и загрузите изменения на GitHub (в GitHub Desktop: **Commit** → **Push**). Всё пересоберётся само:
- **Новый APK** появится в Releases. Он ставится поверх старого, профили винтовок сохраняются.
- **Сайт-приложение** обновится при следующем открытии с интернетом.

## Важно знать

- **Профили хранятся в телефоне.** При удалении приложения они стираются. Перед переустановкой нажмите **«Винтовки → Скопировать профили»** и сохраните текст, например в заметках.
- **APK и сайт хранят профили раздельно.** Перенести их можно той же кнопкой «Скопировать профили» → «Вставить из копии».
- **Ключ подписи APK** (`android/app/popravka-share.keystore`) лежит в открытом репозитории. Для себя и друзей это нормально. Перед публикацией в Google Play заведите закрытый ключ (раздел ниже).

## Для Google Play: свой закрытый ключ

1. Создайте ключ (нужна Java; команда `keytool` входит в её комплект):
   ```
   keytool -genkeypair -keystore my.keystore -alias popravka -keyalg RSA -keysize 2048 -validity 10000
   ```
2. Превратите его в текст: `base64 -w0 my.keystore` (на Mac: `base64 -i my.keystore`).
3. В репозитории: **Settings → Secrets and variables → Actions → New repository secret**. Добавьте четыре секрета:
   - `POPRAVKA_KEYSTORE_BASE64` — текст из пункта 2;
   - `POPRAVKA_STORE_PASSWORD` — пароль хранилища;
   - `POPRAVKA_KEY_ALIAS` — `popravka`;
   - `POPRAVKA_KEY_PASSWORD` — пароль ключа.
4. **Храните `my.keystore` и пароли в надёжном месте.** Без них нельзя выпускать обновления в Google Play.

Учтите: APK с новым ключом не ставится поверх старого. Его придётся установить заново, поэтому сначала сделайте резервную копию профилей.

## Устройство проекта

```
src/                 исходники приложения — меняйте здесь
  index_src.html     интерфейс
  engine.js          баллистическое ядро (сверено с Python-версией и py-ballisticcalc)
  bullets_db.json    база пуль
  cartridges_db.json заводские патроны (Geco, RWS, S&B, Lapua): вес пули, BC и скорость с коробки
tools/build.py       собирает www/ из src/
tools/make_icons.py  рисует иконки
www/                 готовое приложение (собирается автоматически)
android/             Android-проект (Capacitor 8)
.github/workflows/   автосборка APK и публикация сайта
```

Проверить у себя на компьютере (нужен Python 3):
```
python tools/build.py
cd www && python -m http.server 8000
```
Затем откройте http://localhost:8000.
